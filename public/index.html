Como falar com esta entidade

Único ponto de entrada: POST /api/mcp — servidor MCP (streamable http). Não há rota que devolva os dados crus: tudo passa pelas tools. Esta página consome o próprio MCP para montar o cardápio acima.

MCP tools

  • get_menu(category?)
  • place_order(tableId, people, items[])

Alterar o cardápio exige a palavra mágica no parâmetro magicWord:

  • create_menu_item(magicWord, name, category, price)
  • update_menu_item(magicWord, id, name?, category?, price?)
  • delete_menu_item(magicWord, id)
